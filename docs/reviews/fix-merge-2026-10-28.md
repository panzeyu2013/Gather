## 4. 本轮修复（随本提交进 main）

1. **门禁加固**（`PhotoVisibilityGateTests`）：`IS [NOT] NULL` 之外补 `ISNULL/NOTNULL` 与 `ISNULL(col)` 形态；
   改成整段文本匹配（跨行谓词也能抓到，行号按匹配起点换算）；`//`、`*`、`--` 注释行不误报；
   取消 `SchemaCurrent*` 整文件豁免（DDL 注释按 `--` 跳过即可）；逐棵源树断言最少文件数（防某棵树失效后静默漏扫）。
   **反例验证**：临时探针文件分别写 `archived_at IS NOT NULL` 与 `archived_at ISNULL`，两次都红并报出
   `TempGateProbe.swift:3`；删除探针后恢复绿（说明门禁不是空转，也不是只认一种写法）。
2. **l10n 门禁**（`ErrorLocalizationCoverageTests`）：占位符一致性从"只看 % 说明符"扩到同时比 `{{name}}` 序列
   （英文漏写 `{{field}}` 不再静默通过）。
3. **计数原子化**：新增 `SessionRepo.refreshPhotoCount`（单条 `UPDATE sessions SET photo_count = (SELECT COUNT(*) …)`），
   `moveRejected` 改用它，消除"先 COUNT 再 UPDATE"两条语句之间的并发窗口。
4. **文档/门禁**：`docs/ROADMAP.md` 的 384 列 / `user_version=4` → 385 / 5（fix 分支漏改）；
   `check-docs.sh` 纳入 ROADMAP、增加索引/外键比对、版本断言只认含「44 表」的行（历史基线行不参与）。
5. **物理行 API 注释**：`getBySessionPage` / `countBySession` 明确标注"含归档行，禁止用于展示"（port 与实现同步）。
6. **UI 错误呈现**：模板面板切换模板 / 改选择 / 撤销成功后清空过期红字；编辑器失败后重读盘不再覆盖具体原因；
   label 比较 trim 归一（清空后回读 nil 不再报校验失败）；兄弟刷新的死 fallback 清理。

## 5. 剩余 P1（本轮未修，需设计决策/接线）

1. **成员级联系人清空仍报 written**（R2/R5）：内联编辑器把清空的成员写成 `nil`（`MetadataEditorDraft`），
   `replaceContact=true` 时侧车整块替换、内嵌成员仍在；`contactContains` 按"expected 非 nil 才比"放行 → `written`。
   整块清空已由 `JPEG_EMBEDDED_CLEAR_UNSUPPORTED` 覆盖，成员级需要新的显式信号（`MetadataWriteAttributes` 增
   cleared-members 字段或让 planner 把"已存在成员"补进补丁），涉及 IPC 输入契约，留待单独评审。
2. **侧栏照片数不回落**（R3/R5 疑似）：DB 已回落，但 `moveRejectedOut` 只 `loadPage`，未广播 `domainChanged`；
   侧栏读 `DashboardViewModel.sessions`，离开工作台后停止轮询。
3. **内嵌解析不可用时的 fail-open**（R2）：`exif.parse` 返回 nil（APP1 读失败）时回读退化为侧车，
   清空类写入仍报 `written`。需要在 `diskAttributes` 区分"无内嵌"与"读不到内嵌"。

## 6. 其余残余（P2）

1. 从 `_rejects` 搬回（`AssetRepo+Relink` 清 `archived_at`）后不重算 `photo_count`，依赖下一次成功扫描。
2. 写回/分析面（`WritebackService`、`QualityService`、相似度/人脸分析快照）仍含归档件——需产品口径。
3. `LEFT JOIN` 孤儿、`SUM(CASE WHEN …)=0`、嵌套 rep 子查询三处形态缺行为测试（门禁只防"重写"，不防"形态改错"）。
4. 清空最后一个 keywords/label 时回读为 nil → 缓存保留旧值（`if let` 跳过）。
5. 兄弟刷新仍逐张串行读盘（共享侧车组 O(k²) ImageIO 解析）。
6. `JPEG_EMBEDDED_CLEAR_UNSUPPORTED` 的参数是 `field.rawValue`（title/webStatement/contactInfo），中英文界面都带内部标识。
7. `write-back verification failed` / `read-back failed: …` 不是码 → UI 落"发生未知错误"。
8. 模板面板"全失败且批次未入库"仍给撤销入口；撤销 `catch` 用 `String(describing:)` 直接上屏。
9. 编辑器失败后 inspector 不刷新、无就地撤销（`onApplied` 在失败分支之后）。
10. 测试/套件/键数无 ratchet（删用例不会红）；suites 计数含 swift-testing 隐式套件（201 > 143 个 `@Suite` 声明）。
11. 经 `MetadataTemplateService.applyFields`（planner keepExternal）的 JPEG 清空回归缺失，现有用例直调 `applyMetadataAttributes`。
12. 门禁不覆盖运行期拼接的谓词与 `archivedAt` 的非比较读法（`.map`/`if let`），由行为测试兜底。
13. `getBySessionPage` 仍是"含归档行"的实现（仅有注释约束），未加 `visibleOnly` 参数。
