## 0. 执行摘要

1. **骨架是干净的，债集中在展示层与反馈层**。路由（`AppRoute`）、页面生命周期（两级可见性）、事件刷新、命令中心四件套都收口到单一通道；六个模块没有一处指出"架构上无解"的问题。
2. **最伤的三类问题都不是"缺功能"，而是"说了不算"**：按钮印着快捷键但不一定生效、菜单写着"立即写入 XMP"但只回放队列、刷新按钮做着"清空选择"的事。
3. **反馈没有统一出口**：横幅 28 / toast 21 / notice / 弹窗 17，四条通道并存；其中 toast 的按钮很可能点不动（P0 候选）。
4. **状态"完成态"守不住**：相似度回页清空、人物草稿丢弃、控制中心每 3s 整页转圈、导出取消同屏红绿双消息。
5. **键盘是系统性欠账**：30 处 `keyboardShortcut`，只有 5 个进菜单；7 个页面没有任何键盘路径；裸键依赖一个不可见的焦点。
6. **最小窗口（860×560）是当前设计的实际边界而非下限**：页签必然退化成下拉、多按钮横条无 `ViewThatFits`、布局预算仅在侧栏最窄时成立。

## 2. 分模块结论摘要

### A · 外壳 / 导航 / 命令（381 行）
- 层级三分对（侧栏=工作区、页签=页面、标题=会话），但**同一页三个名字**：7/7 页的 `subtitle` 与页签名不一致（图库↔浏览、导出页副标题是 18 字整句，必截断）。
- **P1 横跳**：侧栏切会话被 `enterSession` 记成页级跳转 → A 图库 → 侧栏 B → 返回，回到 A 图库且高亮跳回。这是真 bug。
- **P1 页签无键盘路径**：`.plain` Button，无 shortcut / focusable / 菜单项 → 缺 ⌘1–7。
- **P1 预算失真**：`GatherChromeMetrics` 按 860−180 算预算，实际默认侧栏 220 → 640、最大 260 → 600；`LayoutBudgetTests` 的 680 断言在默认窗口下已透支 40pt。
- P2：首载失败静默成"暂无工作区"；workspace 缺失时裸 ProgressView 无限转圈无出口；⌘W 后 File 菜单全灰且无 ⌘N；导入完成无条件 `openGallery` 把正在编辑的会话整体切走。

### B · 挑片（392 行）
- **竖排四段共用一条 flex 链，唯一被压缩的永远是查看器**：860×560 下查看器 ≈259pt，四宫格每格 ≈187×125，判不了合焦。
- **键盘风险**：裸键只挂在一个 `.focusable()` 查看器上，无 `.focused()`、无初始聚焦、`.focusEffectDisabled()` 抹掉焦点环，而网格 `onAppear` 抢焦点。
- P1：全选只在网格布局；⌘ 加选后 ⇧ 会整体替换选择；「淘汰移出」确认框无张数；`isLoading` 时决策被静默丢弃。
- P1：**同步/写回是"一个动作两个名字"**——菜单「恢复原 XMP」在确认框里叫「清理备份」，实现是回滚 XMP；「立即写入 XMP」只回放 intent（我已复核 `CullingService+Delivery.swift:52-55`）。
- P2：网格布局下 infoBar 整块消失；胶片色标线被文件名条压住；14 段检查器把破坏性动作埋在最底。

### C · 浏览（608 行）
- **P1 刷新毁浏览态**：⌘R/刷新按钮 → `phase=.loading` → 清空选择 + 回顶；事件刷新却只做 `formIntersection`。两条路径语义相反（我已复核）。
- **P1 搜索假空态**：只过滤已加载页，命中在后页时链式拉页，补齐前 `noMatchView` 顶掉网格（分页哨兵一并消失）→ 一旦失败就是死态，无重试出口。
- **P1 灯箱结尾态**：只认打开时的数组，翻到 200/200 变灰，与"已索引 5230"矛盾，关闭不回写游标。
- P2：分页失败无就地重试且错误条在滚动区外；三页 banner 都没传 `onDismiss`；右键菜单两个同名"取消选择"；卡片无悬停无多选。

### D · 分析（336 行，含四张状态机表）
- **P1 相似度回来即清空**：`adoptResult()` 无条件清选择/展开/`writebackResult` → 「确认同步/清理」唯一入口消失，而界面还在指引去点（唯一绕行在挑片页）。
- **P1 过期检测失效**：预计算档只按 threshold 索引，UI 却把当前草稿写进 `resultParams` → `isResultStale` 恒 false。
- **P1 人物草稿无脏状态**：切人/刷新/离页静默丢弃名称与备注。
- **P2 弹窗同节点**：人脸 9 个、人物 3 个；**重复页已按节点拆开 —— 这就是本仓已验证的范式**。

### E · 输出（218 行）
- **长任务链的"收尾段"没设计**：导出失败项不可重试（重跑只能改名→两套文件）、控制中心 running 任务无取消入口、摄取目标目录可任选但必须在校验会话根内。
- **P1 控制中心每轮轮询整页换"加载中…"**（索引期 3s 一轮）——恰恰是盯着看长任务的页。
- **P1 数字打架**：「12 个文件」（实为照片数）/「共 24 个文件」/「写入 24 个文件」。
- **P1 取消语义分裂**：导出取消 = 绿色"已请求取消" + 红色"未知错误"同屏；交付取消 = 正常终态。
- P2：错误样式两套皮（元数据/摄取用 `.caption` + `.red` 字面量，只靠颜色）。

### F · 显示基建（395 行）
- **P1 缩略图内存缓存永不失效**：键不含 mtime、无 invalidate API → C1 改图后仍显示旧图，只有重启才新。**本轮最像"功能坏了"的一条**。
- **P1 "恢复默认"是 `.defaultAction`**：影响面 sheet 里按 Return 直接执行，且偏好默认勾选（我已复核 `ResetImpactSheet.swift:64-71`）。
- **P1 设置页无加载态**：`values` 初始空字典 → 字段全空且可编辑，失焦即保存。
- **P2 设计系统是"覆盖率幻觉"**：ratchet 8 项全绿，但 193 处裸 `.font(`，其中 104 处（`.caption` 54）不在监管内 → Metadata 检查器同一栏 11pt/12pt 混排。
- **P2 a11y 只做标签不做状态**：离线/RAW+JPEG/保留/放弃/3★ 都不在 `accessibilityValue`。
- 本地化静态+动态都干净（1862 键、动态码表全命中、0 中文残留）；真问题是日期不跟 locale、术语分叉（工作区 223 vs 会话 234）。

## 4. 合并优先级

### P0（做完再谈体验）
| # | 事项 | 证据 | 验证方式 |
| --- | --- | --- | --- |
| P0-1 | **toast 命中测试**：容器 `.allowsHitTesting(false)` + 子按钮 `true`（SwiftUI 自祖先收敛，子节点无法重开）→ 「×」「重试」点不动 | `GatherToast.swift:126/156/164`；A/F/我三方独立指出 | 点一次 toast 的 ×；若成立就是导入失败唯一恢复入口失效 |
| P0-2 | **人脸 9 / 人物 3 个 `confirmationDialog` 同节点**：若只弹最后一个，人脸写回确认=点不动 → 破坏性动作无法执行 | `FaceKeywordingView+Confirmations.swift:163-240` | 实机各点一次；对照 `Duplicates` 的拆节点写法 |

> 这两条定级取决于一次点击，验证成本 <10 分钟。**先验 P0-2 再验 P0-1**（P0-2 影响面更大）。

### P1（按用户可见伤害排序，12 条）
1. 缩略图缓存失效（F-1）——改图后显示旧图。
2. 相似度回页清空 + 过期恒 false（D-1/D-2）——无法收尾 C1 写回。
3. 侧栏切会话 → 返回横跳回上一个工作区（A-P1-2）。
4. 刷新语义统一（C-1）——"刷新=就地刷新"，整页重载另设入口。
5. 焦点三件套（B-1/C-3/F-2）。
6. `ResetImpactSheet` 的 Return（F-4）。
7. 控制中心轮询整页转圈（E-1）。
8. 人物草稿丢弃（D-3）。
9. 页签 620 阈值 + 预算失真（A-P1-3/P1-4）——860 下必然菜单。
10. 多按钮横条 `ViewThatFits`（C-4）。
11. 写回命名词与确认张数（B-5/6/7）。
12. 设置页加载态（F-5）。

### P2（按主题批处理，不必逐条修）
- **反馈可回看性**：banner 补 `onDismiss`（28 处只 8 处有）、错误横幅常驻直到用户处理、notice 统一成 banner。
- **a11y 状态语义**：角标/评分/数量进 `accessibilityValue`，去掉"中文逗号拼接"。
- **弹窗拆节点**：人脸/人物照 `Duplicates` 范式改。
- **术语与格式化**：工作区/会话、关键词/关键字、日期 locale、页签与副标题同名。
- **错误样式收敛**：元数据/摄取改用 `NativeBanner` + 主题色（唯一被确认违反主题契约的地方）。
- **键盘补齐**：⌘1–7 切页签、⌘F 搜索、⌥↑↓ 切工作区。
